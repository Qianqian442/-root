# OPPO A55 5G 临时 Root 管理器（Shark 适配分支）

## 目标设备
- 设备：OPPO A55 5G
- Android：12
- 已知内核：4.14.186（需要设备端完整内核版本字符串确认）
- Bootloader：不解锁
- 使用方式：仅手机操作，优先使用 Android 无线调试 / Shizuku 类授权后端

## 当前适配结论
Shark 上游公开 README 当前列出的执行链为 6.6、6.12、6.18 系列，未列出 4.14.186。因此不能把现有执行链直接用于本设备，也不能标记为已支持。

## 开发顺序
1. 中文化界面与设备信息采集。
2. 检测型号、SoC/ABI、Android 版本、完整内核版本、构建指纹与安全补丁日期。
3. 显示明确的兼容性结论；未知内核一律阻止执行，不尝试猜测匹配。
4. 接入可审计、经设备验证的授权后端与 Root 管理器状态检测。
5. 只有在存在合法、公开且针对该设备/固件验证的适配方案时，才评估后续集成。

## 安全边界
- 不解锁 Bootloader，不刷写 boot/vendor_boot/recovery，不修改启动分区。
- 不包含未验证的内核提权载荷，不将其他机型的 exploit 强行移植到 4.14.186。
- Root 结果必须以实际权限验证为准，不以界面提示代替。
- 临时 Root 应在重启后失效；不实现隐蔽持久化。
